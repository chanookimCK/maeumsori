# 마음의 소리함

중고등학생들을 위한 익명 건의함 웹페이지입니다.

## 기능

- 비밀번호 기반 접근 제어
  - 일반 사용자 비밀번호: 1234
  - 관리자 비밀번호: admin1234
- 익명 의견 제출
- 자신이 제출한 의견 확인 및 삭제
- 관리자 페이지에서 모든 의견 확인 및 삭제
- 모던한 UI/UX

## 설치 방법

1. Node.js가 설치되어 있어야 합니다.
2. 프로젝트 폴더에서 다음 명령어를 실행합니다:
   ```bash
   npm install
   ```

## 실행 방법

1. 다음 명령어로 서버를 시작합니다:
   ```bash
   npm start
   ```
2. 웹 브라우저에서 `http://localhost:3000`에 접속합니다.
3. 비밀번호를 입력하여 로그인합니다.

## 보안 주의사항

- 세션 시크릿 키도 환경변수로 관리하세요.
